# NPZDO Sediments Model

This project extends an NPZDO model to study sediment redox reactions and their role in organic matter degradation, focusing on oxygen and nitrate pathways.

## Repository Structure
- **`Project description.pdf`** – Brief description of the project, research question, and model approach.
- **`Updated Project description.pdf`** – Updated description of the project, sketch and chemical equations.
- **`project.ipynb`** - Code
- **`25314___Computational_Marine_Ecological_Modelling___Project.pdf`** - The final project report
